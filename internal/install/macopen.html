How to open Network Doctor Setup

Your Mac stops a file from the internet when Apple has not checked it. Network Doctor is not checked by Apple, so the first time takes four steps.

  1. Try to open the setup file once. Your Mac says it cannot open it. Press Done.
  2. Open System Settings. Then pick Privacy and Security in the list on the left.
  3. Near the bottom, press Open Anyway next to Network Doctor Setup. If your Mac asks again, press Open Anyway once more.
  4. Enter your Mac password when it asks. The setup page then opens in your web browser.

You only do this once. After that, the setup file opens like any other app.

A file you copy from a USB stick or a shared network folder is not blocked. It opens with no extra steps.
